## ⚠️ 需要用户决策：赛题文档是“书生大模型”赛题

赛题文档的硬性要求是：“**必须基于上海人工智能实验室书生大模型**（Intern-S2-397B / Intern S2 Preview、Intern S1 Pro、InternVL 等）”。
可选方向为 AI4S 科学智能体、AI+新场景（工业/城市/医疗/教育）、**开放赋能智能体（自主选题，面向科研或行业）**。
文档中没有金融专属方向，金融研究智能体最贴近“方向 3：开放赋能智能体”。

由此产生两点冲突：
1. 用户计划“正式参赛用 Kimi”，但该赛题要求基于书生模型。如果确实参加此赛题，**主模型必须换成书生**，Kimi/DeepSeek 只能作为开发测试或对照基线。
2. 项目原定的“行业赋能 · 金融智能体”是否就是这个赛题，需要用户确认。如果金融赛题另有细则（可能不限模型），以金融赛题为准。

技术上不受影响：大模型网关是 OpenAI 兼容、可切换供应商的设计，书生 API 也能接入。

## 对研发计划的影响

- **必须有可公开访问的“应用体验链接”**：项目基于快照，可在无国内数据源的环境中部署，需要尽早确定部署平台（境外平台访问书生 API 的延迟需要实测）。
- 技术难度分（30%）看重书生模型的融合深度和前沿技术：计划把 FinSight 工具封装为 **MCP 服务** + **Agent Skills**，主流程使用书生模型做规划与解读，“结论核验”作为可靠性创新点。
- 完整性分（30%）看重可复现：现有的快照 + 哈希 + 一键测试已具备基础，还需补齐 PDF 技术文档。
- 视频不超过 5 分钟：演示脚本围绕“一个问题 → 证据链 → 核验”展开。
