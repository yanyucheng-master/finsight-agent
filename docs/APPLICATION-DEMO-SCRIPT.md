录制前先打开页面，等免费实例唤醒、样本加载完成。主线公司用贵州茅台 600519。公网版本未配置 Key，录屏展示缓存样例与确定性分析：讲清缓存来源，不点实时生成，不出现本机 `.env` 或任何账户页面。
