# 在线体验链接：部署清单

> 2026-11-03 编写。目标：评委打开链接就能看到完整的、核验过的结果；现场实时生成有次数与费用上限；Key 只在服务端。
> 已获用户授权：Render / MASTER LAB 工作区，独立 Free Python Web Service、新加坡区域、单进程。公网版本不配置模型密钥，实时模型生成关闭；提供真实缓存样例与确定性分析。下表中的付费生成配置仅供后续明确启用时参考。

## 1. 部署前提（必须满足）

| 项目 | 要求 | 原因 |
|---|---|---|
| 进程数 | **单进程、单实例**（不要开多个 worker，也不要横向扩容） | 生成任务表在进程内存里；多进程时轮询会找不到任务 |
| 安装方式 | `pip install -e backend`（可编辑安装，在仓库根目录执行） | 数据目录按源码位置定位到仓库里的 `data/`；非编辑安装会找不到快照 |
| Python | 3.10 及以上（开发与测试用过 3.11 / 3.13 / 3.14） | — |
| 前端 | 不需要 Node：`backend/finsight/web/` 已是构建产物 | — |
| 年报 PDF | 不需要 | 分析流程不读取 PDF |

## 2. 命令

- 构建命令：`pip install -e backend`
- 启动命令：`python -m finsight.cli serve --host 0.0.0.0`
  （端口自动读取平台提供的环境变量 `PORT`；没有时为 8000）

## 3. 环境变量

在平台的“环境变量 / Secret”页面填写，**不要**把 `.env` 文件上传到平台或仓库。

| 变量 | 建议值 | 说明 |
|---|---|---|
| `LLM_PROVIDER` | `kimi` | 参赛使用的供应商 |
| `KIMI_API_KEY` | 公网演示不设置 | 无密钥时实时模型生成关闭；本地按需配置 |
| `FINSIGHT_DEMO_MODE` | `1` | 开启演示保护：实时生成必须走有限额的异步接口，前端不能指定供应商 |
| `FINSIGHT_LIVE_DAILY_LIMIT` | `15` | 每天（北京时间）全站实时生成次数；默认 40，评审期建议调低 |
| `FINSIGHT_LIVE_PER_IP_DAILY` | `3` | 每位访客每天实时生成次数 |
| `FINSIGHT_MAX_CONCURRENT_JOBS` | `2` | 同时生成的任务数（排队上限为 3 倍） |
| `FINSIGHT_TRUST_PROXY` | `1` | 平台在反向代理后面时开启，按 `X-Forwarded-For` 识别访客 |
| `FINSIGHT_PROXY_HOPS` | `1` | 可信代理层数：取 `X-Forwarded-For` **从右往左**第 N 个地址（最左边的值访客可以伪造）。若平台前面还有一层 CDN 且两层都追加地址，改为 `2` |
| `LLM_BUDGET_CNY` | `5` | 进程级费用保护（客户端估算，超出后拒绝发送） |
| `LLM_MAX_TOKENS` | `8192` | 单次输出上限；评测② 用同一设置跑 9 家没有被截断，同时降低每次请求的费用占用上界 |
| `LLM_REASONING_EFFORT` | `low` | 默认即为 low |

## 4. 费用怎么控制（务必看）

- 一次实时简报约 0.3 元（评测② 实测平均 0.317 元，估算、不含税）；需要修订时最多约多一倍。按上表 15 次 / 天，最坏情况约 10 元 / 天。
- `LLM_BUDGET_CNY` 是**进程内**的估算保护：服务重启（包括平台在空闲后自动休眠再唤醒）后会从 0 重新计算；次数记录 `data/runs/demo_usage.json` 在临时磁盘上，重新部署后也会清零。
- 所以**真正的硬上限是服务商账户余额**：Kimi 开放平台为预付费，评审期只充值愿意承担的金额（例如 10–20 元），并在控制台查看实际扣费。
- 缓存样例（9 家公司简报 + 2 个问答）与模板简报不调用大模型、不消耗次数，评委不用实时生成也能看到完整效果。

## 5. 部署后自检（每项都要实际点一遍）

1. `https://<你的域名>/api/health` 返回 `"status": "ok"`、`"companies": 9`、`"llm_enabled": false`（本次无密钥公网配置）。
2. `https://<你的域名>/api/demo` 中 `"demo_mode": true`，`live.daily_limit` 与设置一致。
3. 首页 9 家公司都显示风险评级；进入“研究简报”自动打开缓存样例；“模板简报”可以生成。
4. 无密钥公网版本确认实时生成关闭，缓存样例与模板简报正常。后续如需付费实测，应先另行确认预算，再核对服务商账单。
5. 安全自检：浏览器访问 `https://<你的域名>/..%2f..%2f..%2f.env`，应当显示首页而不是任何配置内容。
6. 用手机流量（不连校园网 / 家庭宽带）打开一次，确认评委在国内网络下的加载速度可以接受（海外平台首屏可能较慢，免费实例休眠后首次访问要等几十秒）。

## 6. 无法部署时的替代

材料里写明“本地一键运行”：解压后双击 `scripts\start.bat`，不需要 Key 即可查看全部缓存样例与确定性功能（见 README）。
