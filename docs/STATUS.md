### 用真实数据发现并修正的问题

1. 新版 F10 页面不再内嵌 `hidctype`，导致银行被当作一般企业，资产负债表为空。服务层已改为从 ORG_TYPE 判断公司类型；采集器 v0.1.1 改为自动试探 companyType。**招商银行需要重新采集。**
2. 茅台的应收票据在“应收票据 / 应收款项融资”之间重分类，基数又极小，导致 DSRI = 2.25，模型误报“盈余操纵”。已加入重要性原则：DSRI 取中性值，应收增速规则设 18 天周转门槛。
3. 例行披露的“资金占用专项审计报告 / 汇总表 / 防范制度”被误识别为违规事件，已过滤。
4. 以千元披露的报表换算后产生 ±1000 元尾差，平衡项核验因此误报（宁德时代）。尾差 ≤ 1 万元现视为四舍五入。

## 已知问题与风险

| 问题 | 影响 | 计划 |
|---|---|---|
| 东方财富 push2 行情 / K 线被对方断开（RemoteDisconnected / 502） | 无市值数据，只能用账面版 Z''，无法计算原版 Z | M1：补请求头或换源（如腾讯行情） |
| 云端开发环境无法访问国内数据源和大模型 API | 实时取数、真实 LLM 调用只能在用户本机进行 | 已按“快照 + 本机运行”设计 |
| 有财务公司子公司的企业（如茅台），其经营现金流中混有存贷款类流量 | 净现比、TATA 会受影响 | 后续按“剔除金融业务”口径调整 |
| 退市公司（康得退）仍在披露，存在异常比值（如销售净利率 7549%，可能来自债务重组收益） | 极端值 | 增加极端值提示 |
| 赛事细则未获取；**用户尚未报名** | 交付物可能偏离要求 | 用户尽快报名并提供细则 |
