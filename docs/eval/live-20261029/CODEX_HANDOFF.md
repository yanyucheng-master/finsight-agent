## 范围和费用

用户授权本轮真实接口测试预算上限人民币 10 元，明确要求 Kimi 使用 `kimi-k3.1-pro`。全部简报与问答均使用该模型。DeepSeek `deepseek-flash` 仅用于对话和工具往返连通性测试。没有运行原始 `scripts/llm_smoke.bat`：它使用全局 Python 自动安装依赖，也未提供预算上限，并且即使部分检查失败仍可能返回 0。

使用独立 Python 3.11 虚拟环境、项目原始代码和本地快照。按官方国内标价将 Kimi 所有输入都按普通输入计、DeepSeek 按高峰且全部不命中缓存计，基于供应商返回用量估算约人民币 1.802882 元，不含适用税费，不是账单实扣；实际账单须查两家控制台。每次提交前预留输入 UTF-8 字节数加额外余量及输出上限，计费价格按公开价格的两倍、预留总额上限 8 元，不自动重试。成功请求按返回 token 用量和两倍单价重新预留，失败或无用量请求保留原预留。所有 19 次均返回成功及用量，最终保守累计 3.605764 元。保守预留不是服务商服务器端硬限额，也不能代替账单核对。具体记录见 `ledger.json`。

官方价格参考：<https://www.kimi.com/resources/kimi-k3-1-pro-pricing> 和 <https://api-docs.deepseek.com/zh-cn/quick_start/pricing/>。发起请求前核对：Kimi 每百万输入 13 元、输出 68 元；DeepSeek 高峰每百万未命中输入 2 元、输出 8 元。价格和税费以服务商账单为准。

- Kimi 简报：贵州茅台 `report_600519.json` 数字核验 47/47；万科 `report_000002_resume.json` 37/37；康美药业 `report_600518_resume.json` 42/42。三份均为 LLM 模式，均经过一次修订，未报告未通过项。
- Kimi 问答：茅台与同业比较 `ask_1_600519_resume.json`，4 个工具步骤、数字核验 6/6；万科偿债风险 `ask_2_000002_resume.json`，4 个工具步骤、数字核验 14/14。前者包含 `compare_peers`，后者调用了指标、风险信号及报表科目工具。
- 第一轮预算预留达到阈值后停止。`report_000002.json` 是保留的未修订初稿，6 项未通过均为标题中的格式指令数字；`report_600518.json` 是模板降级结果，不是 Kimi 生成。上述 `_resume` 文件才是后续实际模型输出。不要将模板报告计入模型成功结果。
- 数字核验仅适用于核验器抽取到的数字及其匹配逻辑，不证明全文、逻辑关系、时效性和投资结论均正确。

## 需要进一步核查的问题

1. 茅台简报虽然 47/47，通过的数字并列关系仍可能误导：报告同时列出 2025 年经营现金流 615.22 亿元、归母净利润 823.20 亿元及净现比 0.72 倍，但代码 `analytics/metrics.py` 的 `ocf_to_np` 分母是净利润而非归母净利润。证据账本显示净利润 853.10 亿元；615.22/853.10≈0.72，615.22/823.20≈0.75。建议报告明确分母口径并增加跨数字关系的评估，而不仅核验各数字本身。
2. 首次万科初稿复制了标题中的“1–3 句”“3–5 条”等模板约束，核验器将其抽成无证据数字。这是格式污染导致的核验误报，不能等同于财务数值幻觉；后续一次修订去除了这些内容。应分别改进提示和测试核验器的标题场景，避免为了刷高通过率而忽略真正的未引用数字。
3. 万科问答中的“目前”实际基于本地截至 2025 年年报的快照，不能据此确认测试当天的债务现状。应在回答中明确最新可用报告期、采集时间和数据时效限制，并结合受限资金、债务到期结构及公告原文复核。
4. 本轮报告和问答使用的本地快照与核验逻辑未经过独立全面财务审计；预警模型和定性归因须单独评估，不应宣称实测证明模型可靠或核验器能发现所有错误。
5. 为避免以后误判，建议修复原冒烟脚本的进程退出码与各项失败、模板降级之间的关系；依赖安装建议采用项目虚拟环境及明确版本约束，避免覆盖全局 Python。预算控制需由实际测试入口落实并处理重试、超时与用量缺失。
