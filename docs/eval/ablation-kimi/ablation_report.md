### A 组“有归属”的数字匹配的是哪一期

A 组有 43 个数字在证据库中找到了数值一致的证据。核验器按数值匹配、不区分期间，其中匹配到报告期证据 0 个，匹配到往期证据 43 个：句中写明往期年份 13 个，只写了报告期年份 2 个，句中没有年份 28 个。只写报告期年份的，多半是把往年数字标成了报告期；没有年份的多见于表格，需要看表头判断。

A 组没有写出可核验数字的公司：002069（如拒绝作答并标注“待核实”）。这类简报计入简报数，问题数字为 0 是因为没有作答。

## 局限

* 样本规模：9 家公司，每组单次生成。
* 核验器按数值匹配：A 组数字“有归属”说明证据库中有相同数值，指标未必对应（例如编造的 12.34% 可能恰好等于某个无关增速）；“无归属”也可能来自证据库缺项。问题数字率与实际错误率之间没有固定的大小关系，实际错误以原始财报为准。
* 抽检表附有系统找出的最接近证据，判定以原始财报为准，无法确认的记为“不确定”。抽检表去掉了引用标记，A 与 B/C 的行文风格仍可区分；每组约 20 个数字，区间较宽。
* A 组要求写最新财年的数字，模型训练数据可能没有包含该年报（训练截止期未核实）。问题数字率可能受这一因素影响，本实验没有分离出具体原因。
* A 与 B/C 的提示词、证据和规则都不同；更换模型或提示词，结果会变化。
* A 为空或被截断、C 降级为模板或被截断的公司不计入统计，名单见上文。
