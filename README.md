# FinSight Agent

**可验证的上市公司财务风险研究智能体** —— 每一个数字都有出处，每一个结论都可核验。

参赛方向：第三届“兴智杯”全国人工智能创新应用大赛 · 行业赋能 · 金融智能体创新应用。

## 它做什么

输入一个 A 股代码，FinSight 依次执行以下步骤：

1. 从公开数据源（东方财富 F10、巨潮资讯）读取**原始响应快照**，每份都带 URL、抓取时间和 SHA-256；
2. **先核验数据**：会计恒等式、跨期连续性、与数据源发布指标的交叉比对；
3. 用确定性引擎计算 30 多个指标和 Beneish / Altman / Piotroski 三大模型，每个数字的公式和输入都登记在**证据账本**中；
4. 生成风险信号，文本中内联证据引用，点开即可回溯到原始字段。

下一阶段，大模型将基于证据账本撰写研报、回答问题，由核验器逐条核对其中的数字和结论。

## 快速开始（Windows）

```bat
:: 1) 采集样本数据（只用标准库，不装任何东西）
scripts\collect.bat

:: 2) 安装并启动（需要 Python 3.10+，例如 Anaconda）
pip install -e backend
python -m finsight.cli diagnose 600519
python -m finsight.cli serve      :: 浏览器打开 http://127.0.0.1:8000/docs
```

## 目录

```

backend/tests/      单元测试 + 基于真实快照的集成测试
data/snapshots/     原始响应快照（manifest.jsonl + objects/）
docs/               赛事核对 · 设计 · 路线图 · 开发状态
scripts/            采集脚本 · Windows 启动脚本
```

## 数据与合规

数据仅取自公开披露渠道，用于非商业的研究与竞赛原型。采集器限速访问，保存原始响应以便审计，不转售或再分发数据。
本项目输出的是财务风险排查线索，**不构成投资建议**。
